04 · The research agent

Automation with an evidence brake

The agent accelerates discovery and normalization. It does not get the final word on commercial gates or ambiguous documentation.

01 / SEED

Normalize the list

Maps every app into one strict schema and separates product identity from similarly named tools.

02 / DISCOVER

Prefer first-party docs

Searches auth, developer onboarding, API references, MCP pages and plan language; records the source.

03 / ADJUDICATE

Score buildability

Combines surface breadth, credential path, approval gate, confidence and action risk into one verdict.

04 / VERIFY

Sample and correct

Checks two apps per category by hand, logs misses and downgrades claims that cannot be verified.

Runnable triggernpm run research -- --verifyrecomputes counts + checks the 20-source sample
